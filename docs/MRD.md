## 1. 프로젝트 개요

**Handwrite2KaTeX**는 사용자가 마우스 또는 스타일러스 펜으로 입력한 수식 손글씨를 실시간으로 LaTeX 코드로 변환하고, KaTeX 렌더링 엔진을 통해 수학적으로 정확한 수식 이미지를 즉시 시각화해주는 크로스플랫폼(Web / Android / iOS) 서비스이다.

---

## 2. 시장 분석

### 2.1 시장 규모 및 동향

| 구분 | 내용 |
|------|------|
| 교육 기술(EdTech) 시장 | 2025년 글로벌 약 $4,040억 규모, 연평균 성장률(CAGR) 약 13.4% |
| 수학/STEM 교육 SaaS | 온라인 과외·LMS 수요 급증, 수식 입력 불편 문제 지속 |
| AI OCR / 수식 인식 | Mathpix, Desmos, WolframAlpha 등 시장 확대 중 |
| 모바일 학습 비중 | 전체 교육 트래픽의 65% 이상이 모바일 기기 유입 |

### 2.2 문제 정의 (Pain Points)

1. **수식 입력 장벽**: LaTeX를 모르는 학생·교사는 복잡한 수식을 디지털로 표현하기 어렵다.
2. **단절된 워크플로우**: 손으로 수식을 쓴 후 디지털로 옮기는 과정이 번거롭고 시간이 소요된다.
3. **플랫폼 분절**: 기존 도구들은 웹 전용이거나 모바일 전용으로, 기기 간 일관된 경험을 제공하지 못한다.
4. **실시간 피드백 부재**: 입력 후 변환 결과를 확인하는 데 추가 단계가 필요하다.
5. **이력 관리 불가**: 이전에 입력한 수식을 재사용하거나 학습 이력을 분석하는 기능이 없다.

### 2.3 경쟁사 분석

| 서비스 | 강점 | 약점 | 차별화 기회 |
|--------|------|------|-------------|
| **Mathpix** | 높은 OCR 정확도, API 제공 | 유료 구독 필수, 모바일 UX 미흡 | 무료 티어 + 실시간 렌더링 |
| **Microsoft Math Solver** | 카메라 인식, 무료 | 단방향 결과 제공, LaTeX 편집 불가 | 양방향 편집·이력 관리 |
| **Desmos** | 직관적 그래프, 무료 | 손글씨 입력 미지원 | 손글씨 → 수식 변환 |
| **MyScript Nebo** | 펜 입력 최적화 | 수식 특화 기능 부족, 유료 | STEM 특화 + KaTeX 렌더링 |
| **WolframAlpha** | 수식 계산 강점 | 손글씨 미지원, 유료 | 입력 편의성 + 실시간 피드백 |

### 2.4 시장 기회

- **교육 기관**: 대학·고등학교의 디지털 노트 채택 가속화
- **온라인 과외 플랫폼**: 수식 공유 기능이 필요한 화상 강의 솔루션
- **논문·기술 문서 작성자**: LaTeX 지식 없이 빠른 수식 초안 작성
- **STT/AI 연동 학습 앱**: 수식 인식을 기반 AI 튜터 기능 확장

## 3. 목표 사용자 (Target Users)

### 3.1 Primary Persona

| 페르소나 | 설명 | 핵심 니즈 |
|----------|------|-----------|
| **수학 학생** (중·고·대학생) | 태블릿/모바일로 학습하는 Z세대 | 손으로 쓴 수식의 즉각적인 디지털 변환 |
| **수학 교사·강사** | 온라인 강의 자료 제작자 | LaTeX 없이 빠른 수식 콘텐츠 생성 |
| **이공계 연구자** | 논문·발표 자료 작성자 | 초안 수식 신속 입력 후 LaTeX 추출 |

### 3.2 Secondary Persona

| 페르소나 | 설명 |
|----------|------|
| **LMS 운영사** | Handwrite2KaTeX API를 자사 플랫폼에 통합하는 B2B 파트너 |
| **디지털 노트 앱** | 수식 입력 모듈로 SDK 형태의 통합을 원하는 파트너 |

## 4. 핵심 가치 제안 (Value Proposition)

> **"펜을 들고 쓰면, 완벽한 수식이 완성됩니다."**
>
> 손으로 쓴 수식이 실시간으로 LaTeX와 KaTeX로 변환되어 학습·강의·연구의 생산성을 비약적으로 향상시킵니다.

| 가치 | 설명 |
|------|------|
| **즉각성** | 캔버스 입력과 동시에 LaTeX·KaTeX 변환 결과 표시 |
| **접근성** | Web, Android, iOS 동일 경험 제공 |
| **이력 관리** | DB 기반 수식 저장·검색·재사용 기능 |
| **정확성** | SOTA LLM/Vision 모델을 통한 높은 인식 정확도 |

## 7. 성공 기준 (Success Criteria)

- [ ] Web / Android / iOS 에서 동일한 Canvas 입력 UX 제공
- [ ] 손글씨 → LaTeX 변환 정확도 ≥ 92%
- [ ] 변환 결과 응답 시간 ≤ 2초 (P95)
- [ ] KaTeX 실시간 렌더링 지연 ≤ 200ms
- [ ] 사용자 수식 이력 DB 저장 및 조회 기능 제공
